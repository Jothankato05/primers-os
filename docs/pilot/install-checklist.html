Install checklist: one PC

1. Before installing (see the rollback plan)

  • The PC's current system is backed up: image name on drive
  • Windows licence or product key noted, if any; BitLocker recovery key saved, if the disk is encrypted
  • The USB stick was written from the release's ISO, and its checksum was checked (sha256sum -c SHA256SUMS)

2. Install

  • Started the PC from the USB stick (Secure Boot can stay on)
  • Double-clicked Install PRIMERS OS; on the Partitions page chose Erase disk
  • Administrator login name labadmin; password from the lab administrator (never written on this sheet)
  • Left Restart now ticked, pressed Done; removed the USB stick when asked and pressed Enter
  • The PC started PRIMERS OS from its own disk (no USB stick in)

3. Firmware (after the install)

  • Firmware (BIOS/UEFI) password set, kept by the lab administrator
  • Boot from USB, CD/DVD and network: off; the internal disk first
  • Secure Boot on (UEFI PCs) · Case lock or tamper seal, if the case can be opened

4. Set up (signed in as labadmin, in a terminal)

  • Institution named in the privacy notice:
    sudo primers-privacy controller --name "Veritas University" --contact "…" --dpo "…"
  • sudo primers-lab enable, then restarted; the login screen shows the shared lab account
  • Paired with the invigilator's PC: sudo primers-fleet join <invigilator PC> <code> (on pairing day)
  • Network cable plugged in; a web page opens in Primers Lite Bee

5. Measure

  • Shut the PC down completely, then pressed the power button with a stopwatch running. Power button → login screen: s
  • Signed in as labadmin, waited 2 minutes, opened the PRIMERS Brain and typed benchmark:
    Boot to login s · RAM in use MB · Disk used GB · Disk type HDD / SSD
  • Copied the report (~/.local/share/primers/benchmarks/) to the USB stick

6. Exam kiosk test (with a practice exam started on this PC)

  • Signed in to the shared lab account: the exam opened full screen, with the "exam is logged" line in the bar
  • Alt+Tab, Ctrl+Alt+T, Ctrl+Alt+F2, Print Screen and right-click do nothing
  • A link to another website is refused with a notice
  • Finish exam returns to the login screen
