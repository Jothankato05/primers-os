# Primers OS logo

Colours: Night Ink #12161C, Chalk #F5F2EA, Ready Green #1E9E62 (cursor and states only).
Wordmark: Bricolage Grotesque Bold "primers" + Regular "OS", outlined in the SVGs.
Mark: P on a 64 unit grid with a block cursor at its foot. The cursor blinks on boot (1.06 s, steps). Respect prefers-reduced-motion.

svg/  master vector files. Use these wherever possible.
png/  app icons 16 to 1024, favicons, lockups for places that need bitmaps.
favicon.ico  16, 32, 48.

Clear space: the cursor's width on every side. Minimum: mark 16 px, horizontal lockup 96 px wide.
Do not stretch, recolour the cursor, move the cursor, add gradients or shadows, or retype the wordmark.
